# Frontend

Next.js (App Router, TypeScript) frontend for the Design Compatibility Checker.

This is part of a larger monorepo — see the [root README](../README.md) and
[`PROJECT_SPEC.md`](../PROJECT_SPEC.md) for project-wide context. Full setup
and usage documentation will be added as part of Phase 1 completion.

## Local development

```bash
pnpm install
pnpm dev
```

Requires Node.js >=20.9.0.

## Quality checks

```bash
pnpm lint
pnpm format:check
pnpm typecheck
pnpm test
pnpm build
```
